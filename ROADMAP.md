# Roadmap

High level only; details change as the project takes shape.

| Phase | Outcome |
|---|---|
| 0 | Repository, CI, security baseline |
| 1 | A single box: image build, persistent work disk, secure remote access, web IDE and desktop browser |
| 2 | The `ozbox` CLI: create, pause, resume, resize, destroy; secrets handling |
| 3 | Agent engines: run and supervise coding-agent sessions, with permissions and approvals |
| 4 | Fleets: many boxes, a control plane, boxes that coordinate work |
| 5 | More providers and a web dashboard |
