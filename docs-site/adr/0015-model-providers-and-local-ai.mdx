**Decision.** Oz Box holds no model key and no model account of its own. A person adds a provider (Anthropic, OpenAI, Google
Gemini, OpenRouter, Mistral, Groq, Together, AWS Bedrock, Azure OpenAI, Google Vertex AI, or any OpenAI-compatible
server) and gives it a key, or for the three cloud providers the key of their own cloud account.

1. **Keys are write-only.** A key lives in the secret store (never settings, never `/work`, never argv, a URL, a log or an
   answer). It is read at the moment a request is built, goes into a header only, and a provider's error text is scrubbed of it.
   A request prints without its header values. A run never receives the key: it gets a per-run token and the credential
   broker's address (ADR 0017), and the broker adds the key to the request.
2. **The check is free.** "Test connection" asks the provider which models these credentials can use (a list call, no
   prompt). Sending a one-word test message is a separate, explicit action that says it can cost a fraction of a cent.
3. **Prices are estimates with a source and an age.** A built-in table carries the vendor's pricing page and the month it was
   checked; an old entry is called old. A person's own price wins. A model without a price shows no price and adds nothing to a
   total: a figure is never invented. Usage is counted from what runs record (names and token counts, never prompts).
4. **One engine, one choice.** Each agent engine has a provider, a model and a fallback for the fleet, and a box may override
   it. An engine is only offered providers it can speak to.
5. **Local models never face a network.** Ollama or vLLM on a GPU box listen on the box's loopback address. A local endpoint
   is registered as a provider that runs on that box, and is asked through the box, not over the network. An endpoint the
   person runs elsewhere may be reached over plain http only at a loopback or private-network address that they mark as their
   own; link-local (the cloud metadata address), shared (CGNAT) and public addresses over http stay refused (ADR 0005).
   Downloading a model is plan-then-apply: the plan shows the download size, the disk it takes and the GPU memory it needs
   before anything is fetched, and a stale plan is refused (ADR 0002).
